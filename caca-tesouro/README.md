# Caça ao Tesouro — Futuro do Trabalho

Este pacote contém páginas HTML separadas para cada charada.

## Atualização desta versão

As alternativas agora trazem o nome da habilidade/competência e sua definição, para que os alunos possam interpretar melhor cada resposta.

## Arquivos principais

- `index.html`: página inicial de apoio, com a charada inicial, links de teste e definições das competências.
- `charada-01-quando-o-cenario-muda.html`
- `charada-02-aprender-nao-termina.html`
- `charada-03-dados-que-aprendem.html`
- `charada-04-antes-de-decidir-investigar.html`
- `charada-05-quem-ajuda-outros-a-crescer.html`
- `charada-06-conectar-e-proteger.html`
- `charada-07-ideias-novas-problemas-reais.html`
- `charada-08-mover-pessoas-proposito.html`
- `gabarito-organizacao.html`: uso interno da organização.
- `style.css`: estilos compartilhados.

## Formulário de respostas

Todas as páginas usam o formulário:
https://forms.cloud.microsoft/r/PGXiqFQ8v9

## Como gerar QR Codes

Depois de publicar a pasta em um site, gere um QR Code para cada arquivo HTML.

Exemplo:
`https://seudominio.com/caca-tesouro/charada-03-dados-que-aprendem.html`

## Observação

O arquivo `gabarito-organizacao.html` deve ser mantido apenas com a equipe organizadora.
